Install Household Chores

Put the chore list on every home screen.

Install the web app for quick access, or download the Android APK if your household prefers a native app. The web install is usually the easiest option for iPhone and iPad.

Install prompts and web-app features work best on HTTPS. Localhost is the only common exception.
